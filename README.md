## Практика

В репозитории находятся мои практические SQL-запросы на учебной базе данных HR Schema.

Я практикую:

- объединение таблиц с помощью JOIN;
- группировку данных и агрегатные функции;
- SELF JOIN;
- подзапросы (Subqueries);
- коррелированные и некоррелированные подзапросы;
- работу с датами;
- использование Oracle-функций;
- написание сложных SQL-запросов для решения аналитических задач.
