# SQL Practice — Oracle SQL

Мой учебный проект по изучению SQL и Oracle SQL на базе данных HR Schema.

## Изученные темы

### SQL
- SELECT
- WHERE
- ORDER BY
- DISTINCT
- GROUP BY
- HAVING
- Агрегатные функции
- JOIN
- SELF JOIN
- Oracle JOIN
- Различные типы JOIN

### Oracle SQL
- TO_CHAR
- TO_DATE
- TO_NUMBER
- Oracle-specific функции и синтаксис

### Functions
- Single-row functions
- Multiple-row functions
- Числовые функции
- Строковые функции
- Функции для работы с датами
- Функции преобразования типов

## Практика

В репозитории находятся мои практические SQL-запросы на учебной базе данных HR Schema.

Я практикую:
- объединение таблиц;
- работу с группами и агрегатами;
- SELF JOIN;
- работу с датами;
- использование Oracle-функций;
- написание более сложных SQL-запросов.

## Цель

Продолжать развивать навыки SQL, углубляться в Oracle SQL и постепенно формировать портфолио проектов.
